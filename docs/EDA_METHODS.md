# Phase 4 EDA Methods

## Input and reproducibility

The EDA reads `backend/data/processed/cleaned_usgs_2025.csv`, which is generated by the Phase 3 pipeline. The raw USGS CSV and the ADM2 GeoJSON are not edited by the EDA.

Run the analysis from the `backend/` directory with:

```powershell
cd backend
.\.venv\Scripts\python.exe -m app.analysis.run_eda
```

The reusable implementation is in `backend/app/analysis/eda.py`. The notebook calls those same functions so that exploratory work and repeatable output use one implementation.

To open the notebook interactively, run `jupyter lab` from the project root using the backend environment, then open `backend/notebooks/phase4_eda_usgs_2025.ipynb`.

## Calculations

- Basic statistics include count, minimum, first quartile, median, mean, third quartile, maximum, and sample standard deviation for magnitude, depth, latitude, and longitude.
- Magnitude distribution is shown as a histogram and box plot. Summary bins use `<4.5`, `4.5-<5.0`, `5.0-<5.5`, `5.5-<6.0`, `6.0-<6.5`, `6.5-<7.0`, and `>=7.0`.
- Depth distribution is shown as a histogram and a log-count histogram. Descriptive groups are shallow `<70 km`, intermediate `70-<300 km`, and deep `>=300 km`.
- Temporal distribution counts records by UTC calendar month.
- Geographical distribution plots longitude and latitude, coloured by the Phase 3 assignment status.
- Province activity counts only records assigned by point-in-polygon intersection with an ADM2 feature. No nearest-province fallback is used.

## Interpretation limits

This is a descriptive analysis of one historical USGS year. A high count may reflect catalogue coverage, location, reporting, or a concentrated sequence; it is not by itself evidence of higher long-term hazard. The analysis does not estimate probability, causation, recurrence, or prediction. The 652 offshore/unassigned Philippine-labelled records are retained and shown separately rather than silently removed.
